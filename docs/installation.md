# Installation

Pocket Timer installs with pipx. Install pipx first, then follow the steps for your system. This page
assumes pipx is already installed.

## macOS

Run `pipx install pocket-timer` in a terminal. Then run `pocket --version`. The command prints the
version number.

## Linux

Run `pipx install pocket-timer` in a terminal. Then run `pocket --version`. The command prints the
version number.

## Windows

Run `pipx install pocket-timer` in a terminal. Then run `pocket --version`. The command prints the
version number.

## Check the installation

Run `pocket --version`. If the command prints the version number, Pocket Timer is installed and ready.
