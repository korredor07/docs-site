# Installation

You install Pocket Timer with `pipx`. The command is the same on macOS, Linux and Windows.

## macOS

You need Python 3 and pipx. Then run:

```
pipx install pocket-timer
```

## Linux

You need Python 3 and pipx. Then run:

```
pipx install pocket-timer
```

## Windows

You need Python 3 and pipx. Then run:

```
pipx install pocket-timer
```

## Verify the installation

Run `pocket --version`. The command prints the installed version.

If the terminal says the command is not found, restart the terminal and try again. If that does not
help, check that the pipx bin folder is on your PATH.

Once the version prints, start your [first session](getting-started.md#your-first-session).
